# Genetic Algorithm for Classification

A simple Python project implementing a **Genetic Algorithm (GA)** for classification tasks using **single-point crossover**.  
This project is designed to demonstrate evolutionary computation concepts and GA operations like selection, crossover, and mutation.

## Features

- Implements **Genetic Algorithm** for classification problems  
- Supports **single-point crossover**  
- Includes **selection, crossover, mutation**, and fitness evaluation  
- Easy to modify GA parameters (population size, mutation rate, etc.)
